POST/v1/scansCreate or reuse a scan

Accepts a supported chain and token address. Returns a completed result or a pending scan identifier.

Required
chain, address
Responses
200, 202, 400, 429
GET/v1/scans/:scan_idRead one scan result

Returns scan status, holder-risk verdict, and supporting evidence fields for a known scan.

Required
scan_id
Responses
200, 404, 429
GET/v1/tokens/:address/riskRead latest token verdict

Returns the latest available holder-risk verdict for a supported token address.

Query
chain=bnb
Responses
200, 404, 429
GET/v1/verdictsRead a verdict feed

Returns a cursor-paginated preview feed of recently changed holder-risk verdicts.

Optional
cursor, band, limit
Responses
200, 400, 429

Contract boundary

Holder risk is one signal, not a safety guarantee.

Covered by this preview

  • Holder concentration
  • Linked wallet groups
  • Fresh-wallet participation
  • Observed sniper participation

Not covered by this score

  • Owner privileges
  • Token taxes
  • Honeypot behavior
  • Mint or upgrade authority
